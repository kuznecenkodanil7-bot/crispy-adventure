# Moderation Helper GUI

Клиентский Minecraft-мод для **Java Edition / Fabric / 1.21.11**. Это не PE/Bedrock.

Мод помогает модератору быстро выдавать наказания через GUI, открываемый по СКМ по нику в чате, сохраняет скриншоты, ведёт статистику сессии, хранит недавних игроков и управляет записью OBS через `obs-websocket`.

## Что реализовано

- СКМ по сообщению в чате открывает меню наказаний.
- В главном меню крупно показывается ник: `Кого хочешь наказать: nick`.
- Категории наказаний разделены: `Предупреждение`, `Мут`, `Бан`, `Бан по IP`.
- Для `Mute`, `Ban`, `IPBan` сначала выбирается причина, потом срок наказания — как на Minecraft-style экране со списком правил.
- Для `Warn` время не требуется.
- Ник парсится с игнорированием рангов: `HT5`, `LT5`, `RHT3`, `XLT1`, `I`–`X` и т.д.
- Игнорируются серверные слова перед ником: `anarchy-alpha`, `anarchy-beta`, `anarchy-gamma`, `anarchy-new`, `duels`.
- Ник фильтруется под Minecraft-формат: латиница, цифры, `_`, длина 3–16.
- Скрин делается **до открытия меню** и сначала сохраняется в `moderation_screenshots/temp/`.
- Если в сообщении есть `Tick Speed`, `Reach`, `Fighting suspiciously`, `Block Interaction`, скрин не делается, но меню открывается.
- После наказания скрин переносится в `warn`, `mute`, `ban`, `ipban`.
- Итоговое имя скрина: `{nick}_{punishment}_{duration}_{reason}_{datetime}.png`.
- Запрещённые символы в имени файла заменяются на `_`.
- Warn/Mute/Ban/IPBan отправляют команды в чат от имени игрока.
- Warn отправляет `/warn nick reason`, без времени.
- Mute/Ban/IPBan отправляют `/mute nick duration reason`, `/ban nick duration reason`, `/ipban nick duration reason`.
- Недавние игроки без нумерации; клик по нику копирует ник и открывает меню наказаний.
- Клавиша `H` открывает только панель статистики и недавних игроков. Она не ищет ник и не делает скрин.
- Клавиша `G` останавливает OBS-запись, но **не срабатывает, когда открыт чат**, чтобы буква G не мешала набору сообщения.
- Кнопка `Вызвать на проверку` отправляет:
  - `/check {nick}`
  - `/tell {nick} Здравствуйте, проверка на читы. В течении 5 минут жду ваш Anydesk(наилучший вариант, скачать можно в любом браузере)/Discord. Также сообщаю, что в случае признания на наличие чит-клиентов срок бана составит 20 дней, вместо 30.`
- При вызове на проверку запускается OBS-запись.
- Над хотбаром появляется таймер `Идёт запись: 00:00`.
- При `ipban` OBS останавливается автоматически, кроме причины `3.8`.
- Автоочистка старых скринов при старте: `DELETE`, `ARCHIVE`, `OFF`.

## Логика экранов

Теперь интерфейс сделан по Minecraft-style схеме:

1. Главное меню: `Предупреждение`, `Мут`, `Бан`, `Бан по IP`, `Вызвать на проверку /check`, `Снять с проверки`.
2. Экран причины: показывает только причины выбранной категории.
3. Экран срока: показывает только сроки, допустимые для выбранной причины.
4. После выбора срока команда сразу отправляется в чат.

В заголовке каждого экрана показывается ник: `Кого хочешь наказать: nick`.


## Причины в версии 1.2.0

Причины уже внесены в `ModConfig.defaultReasons()` и попадут в конфиг автоматически. Если у тебя уже был старый конфиг, мод обновит набор правил по `rulesPresetVersion`.

### Warn

- `2.1` — предупреждение.

### Mute

- `2.2` — оскорбления кого-либо/чего-либо. Варианты времени: `1h`, `12h`, `1d`, `7d`.
- `2.3` — оскорбление родных. Варианты времени: `1d`, `5d`, `15d`.
- `2.4` — сообщения сексуального характера. Время: `2h`.
- `2.5` — неадекватное поведение. Время: `2h`.
- `2.6` — реклама серверов и сторонних ресурсов. Время: `1d`.
- `2.7` — пропаганда/агитация ненависти и вражды. Время: `9h`.
- `2.8` — сторонние ссылки/реклама стримов и видео. Варианты времени: `8h`, `3d`.
- `2.9` — выдача себя за администратора. Время: `12h`.
- `2.10` — угрозы вне игрового процесса. Время: `12h`.
- `2.11` — угрозы наказанием без причины. Время: `6h`.
- `2.12` — обсуждение политики. Варианты времени: `12h`, `7d`.
- `2.13` — введение игроков в заблуждение. Время: `2h`.
- `2.14` — попрошайничество ресурсов/привилегий у администрации. Время: `6h`.
- `2.15` — помехи в голосовом чате. Время: `4h`.

### Ban

- `2.2` — оскорбления кого-либо/чего-либо. Варианты времени: `1d`, `7d`, `2d`.
- `2.3` — оскорбление родных. Варианты времени: `3d`, `7d`.
- `2.6` — реклама серверов и сторонних ресурсов. Варианты времени: `1d`, `14d`.
- `2.7` — пропаганда/агитация ненависти и вражды. Время: `3d`.
- `3.1` — запрещённый никнейм. Время: `perm`.
- `4.1` — донатер без доказательств. Варианты времени: `20d`, `30d`, `15d`, `5d`.

### IPBan

- `3.3` — торговля за реальные деньги. Время: `30d`.
- `3.6` — баги сервера/лаг-машины. Варианты времени: `1d`, `15d`.
- `3.7` — использование/хранение стороннего ПО. Варианты времени: `30d`, `20d`, `15d`, `7d`.
- `3.8` — обход бана за читы. Время: `30d`. При этой причине OBS **не останавливается автоматически**.
- `3.9` — подстрекательство к нарушению правил. Время: `3d`.
- `3.10` — тим с игроком, использующим стороннее ПО. Время: `15d`.

## Сборка локально

Требования:

- Java 21
- Gradle
- Minecraft Java Edition 1.21.11
- Fabric Loader
- Fabric API

Команда сборки:

```bash
gradle build
```

Готовый `.jar` появится в:

```text
build/libs/
```

Файл без `sources` положи в папку:

```text
.minecraft/mods/
```

Также в `mods` должен лежать Fabric API под 1.21.11.

## Сборка через GitHub Actions

В проекте уже есть файл:

```text
.github/workflows/build.yml
```

После загрузки проекта на GitHub открой вкладку **Actions**, запусти **Build Fabric Mod**, потом скачай артефакт `moderation-helper-gui-jar`.

## Настройка OBS

В OBS Studio:

1. Открой `Tools / Инструменты`.
2. Выбери `WebSocket Server Settings`.
3. Включи `Enable WebSocket server`.
4. Порт оставь `4455`.
5. Задай пароль или оставь пустым.
6. В конфиге мода укажи такой же пароль.

Конфиг создаётся после первого запуска:

```text
.minecraft/config/moderation-helper-gui.json
```

Основные параметры:

```json
{
  "rulesPresetVersion": 3,
  "obsEnabled": true,
  "obsHost": "localhost",
  "obsPort": 4455,
  "obsPassword": "",
  "recentPlayersLimit": 15,
  "screenshotCleanupMode": "DELETE",
  "screenshotRetentionDays": 30,
  "screenshotFolder": "moderation_screenshots",
  "checkCommandTemplate": "/check {nick}",
  "checkTellTemplate": "/tell {nick} ..."
}
```

## Управление

Все бинды меняются через стандартные настройки Minecraft:

```text
Options → Controls → Key Binds → Moderation Helper GUI
```

По умолчанию:

- `СКМ` по сообщению в чате — открыть меню наказаний по найденному нику.
- `H` — открыть статистику и недавних игроков.
- `G` — остановить OBS-запись, если чат не открыт.

## Важное ограничение

В Minecraft 1.21.11 чат сильно поменяли: мод хранит последние сообщения через mixin и по координате клика примерно выбирает строку. На стандартном чате это должно работать, но если стоит мод, который полностью меняет чат, формулу в `ChatMessageTracker.guessMessageByMouseY()` может потребоваться подстроить.
